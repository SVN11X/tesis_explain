# servicio

Cloudflare Worker that corrects the oral-defense answers with AI. It is deployed apart from the site.

- Goes here: Worker code in `src/`, D1 migrations in `migraciones/`, its tests in `tests/` and `wrangler.toml`.
- Does not go here: Guide pages or anything the site serves (`public/`, `src/` at the root).
- Naming: kebab-case file names, as the Worker already uses.
