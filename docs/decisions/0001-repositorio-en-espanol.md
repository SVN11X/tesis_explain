# 0001. The repository stays in Spanish except the standard's own files

- Status: accepted
- Date: 2026-11-19
- Proposed by: AI tool, from the standard's language rule
- Accepted by: owner, on 2026-11-19, in the conversation that adopted the standard

## Context

The standard asks for English in repositories. This site is a thesis guide whose audience is Spanish-speaking, and its page names are public URLs such as `problema.html` and `resultados.html`.

## Decision

Content, page names, folder names and code identifiers stay in Spanish. Only the files that belong to the standard (AGENTS.md, DESIGN.md, CHANGELOG.md and the files in `docs/` that the standard defines) are written in English.

## Alternatives considered

Translating everything to English. It would break public URLs and make the content harder for its real readers.

## Consequences

Public URLs stay identical. Contributors who read only English need the English files for orientation. To undo it, translate and add redirects.
